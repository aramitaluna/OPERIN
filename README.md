## 📋 Tentang OPERIN

**OPERIN** adalah *Student Move-Out Circular Marketplace* — platform digital terpadu yang membantu mahasiswa menjual, mendonasikan, mendaur ulang, dan melakukan *upcycling* barang kos saat pindah atau lulus kuliah.

### 4 Pilar Layanan

| Pilar | Deskripsi |
|---|---|
| 🛒 **OPERIN Sell** | Jual-beli barang bekas kos dengan escrow + AI Smart Valuation |
| 💙 **OPERIN Give** | Donasi perabotan ke mahasiswa afirmasi & panti asuhan mitra |
| ♻️ **OPERIN Recycle** | Salurkan material ke bank sampah & industri daur ulang |
| ✨ **OPERIN Upcycle** | Proses barang rusak jadi produk baru bersama mitra pengrajin |

Plus: **OPERIN Pickup** (jasa jemput barang besar) & **OPERIN Point** (hub drop-off fisik)

## 🚀 Cara Deploy ke GitHub Pages

### Opsi A — Upload Manual (paling mudah)
1. Buka repo GitHub kamu
2. Klik **Add file → Upload files**
3. Upload file `index.html` dari folder ini
4. Klik **Commit changes**
5. Pergi ke **Settings → Pages → Source: Deploy from branch → main → / (root)**
6. Website live di `https://USERNAME.github.io/REPO-NAME/`

### Opsi B — Via Git (jika sudah install Git)
```bash
git init
git add index.html README.md
git commit -m "Initial commit: OPERIN mockup website"
git remote add origin https://github.com/USERNAME/REPO-NAME.git
git push -u origin main
```
Lalu aktifkan GitHub Pages di Settings.
